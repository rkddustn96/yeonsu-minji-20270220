# 모바일 청첩장

`web/`에 있는 청첩장을 GitHub Pages로 배포합니다.
디자인 원본 PSD와 작업 사진 폴더는 `.gitignore`로 업로드 대상에서 제외합니다.
웹사이트에 사용하는 사진·폰트·음악은 `web/` 안에 포함되어 있습니다.

## 최초 배포

1. GitHub에 저장소를 만듭니다. 무료 계정으로 배포하려면 Public 저장소를 선택합니다.
2. 이 폴더의 `.github/`, `scripts/`, `web/`, `.gitignore`, `README.md`를 저장소의 `main` 브랜치에 올립니다. `web` 내부만 올리지 않습니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
4. **Actions → Deploy wedding invitation → Run workflow**를 실행합니다.
5. 완료되면 **Settings → Pages**에 표시되는 사이트 주소를 공유합니다.

일반적인 주소: `https://GITHUB_ID.github.io/REPOSITORY/`

이후 `main`에 수정 파일을 올리면 자동으로 다시 배포됩니다.
카카오톡 미리보기 이미지와 공유 주소는 배포 중 실제 Pages 주소로 설정됩니다.

## 배포 후 확인

- 휴대전화에서 사진, 갤러리 확대, 음악 버튼, 계좌 복사, 링크 공유를 확인합니다.
- 네이버 지도 API를 사용하는 경우 네이버 클라우드 콘솔의 해당 애플리케이션에 실제 배포 주소를 Web 서비스 URL로 등록합니다. 지도가 인증되지 않으면 기존 네이버 지도 링크가 표시됩니다.
- 카카오톡으로 사이트 링크를 보내 미리보기 이미지를 확인합니다. 이전 미리보기가 남아 있다면 카카오 공유 디버거에서 캐시를 갱신합니다.

배포된 청첩장은 링크를 가진 누구나 열 수 있으며, 페이지에 포함한 사진과 계좌 정보도 함께 공개됩니다.
